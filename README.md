# Weight Tracker 

<img width="1920" height="1080" alt="Weight Tracker" src="https://github.com/user-attachments/assets/6ae1905f-f82d-4c81-8791-7e7943a13f52" />

A simple, lightweight, and responsive web application designed to help users log, monitor, and track their body weight progress over time. 

Built with a focus on accessibility and performance, this project is configured as a **Progressive Web App (PWA)**, meaning it can be installed directly on mobile devices and desktops for a native-app-like experience.

## Live Demo
You can try the application directly in your browser here:
[Live Demo - Weight Tracker](https://lazykunn.github.io/Weight-Tracker/)

## Key Features
* **Simple Logging:** Quickly input and track weight entries.
* **PWA Ready:** Installable on any compatible device (Android, iOS, Windows, Mac) directly from the browser.
* **Offline Capabilities:** Uses a Service Worker (`sw.js`) to cache resources and ensure the app loads even without a stable internet connection.
* **Lightweight:** Built entirely with vanilla web technologies. No heavy frameworks.

## Tech Stack
* **HTML5:** Semantic structure and layout.
* **JavaScript (Vanilla):** Application logic and Service Worker registration.
* **PWA:** `manifest.json` and Service Workers for installability and offline support.
